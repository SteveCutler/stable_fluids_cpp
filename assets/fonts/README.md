# Roboto Mono

Unmodified Roboto Mono variable font, used at its default weight for the application UI.

Source: https://github.com/google/fonts/tree/aa24661a5ba24c8f8a550a16fb13198719fc2c23/ofl/robotomono

Upstream filename: `RobotoMono[wght].ttf`; stored as `RobotoMono.ttf` for a simple asset path. Font contents and internal names are unchanged.
